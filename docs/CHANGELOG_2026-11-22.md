# Changelog: targeted modifications (prompt 01_FINAL_TARGETED_MODIFICATIONS_PRIORITY)

Base: the project on GitHub `Eya-Manaa2/Blue-Thread` (commit c774f77). The old `blue-thread.zip` from the package was not used, because it is an older version.
Unchanged: UI style (UiKit, Fira fonts, colours), soundtrack, controls, score, Supabase (`database/migrations/002_five_bins.sql` produced byte for byte), network guard (NetGuard), network HUD.

## File by file

| File | Change |
|---|---|
| `scripts/ui/MainMenu.gd` | Removed **CHOOSE A SHORE** (button and panel), **JURY DEMO MODE: ON/OFF** (button) and the **footer text** (credits). Added **CONTINUE · <shore>**, shown only when a saved game is in progress (otherwise PLAY THE STORY stays as it was). Jury mode remains available with `?demo=1` or the J key, with no visible button. |
| `scripts/ui/ProfileSetup.gd` (new) | "What should we call you?" screen: name trimmed, 2–20 characters, letters (accents included), spaces / ' / -, clear error messages. **6 avatars** shown as 3D previews (SubViewport): boy with dark skin, boy with fair skin, girl with red hair, blonde girl, girl wearing a hijab, girl with curly hair. Glow on the selected card. **START** is enabled only with a valid name **and** a chosen avatar. Keys 1–6 or ← → also select an avatar. Pre-filled from the save. |
| `autoload/GameState.gd` | `validate_name()`, `set_profile()`, `display_name()`. Oxygen **exactly 1 unit/s** (`maxf(air - 1.0*delta, 0)`, also in jury mode). `collect()` fills the **real inventory** for the level. `distractor_picked()`, deaths counter. `save_game()`/`load_game()` save name, avatar, story restoration, completed levels, rewards, score and inventory (local only, never sent to the server). |
| `scripts/data/GameData.gd` + `tools/gen_data.py` + `tools/levels_part.gd.txt` | Recipe items and distractors (not on the server). L1: newspaper, notebook pages, paper bag, cardboard, letters; distractors: PET bottle, metal can, broken toy. L2: knitted sweater, scarf, knitted hat, cardigan, leftover yarn; distractors: plastic tub, broken ceramic, metal can. L3: 5 PET bottles; distractors: glass bottle, metal can, paper packaging. Batteries go to SPECIAL. Recycling steps: PAPER 4, TEXTILE 5, PET 7, each with what to do / why / interaction / feedback. `COLLECT_TIME` 180 s, `DISTRACTOR_PENALTY` 5 s. Exact lines: `WORKBENCH_LINE`, `DEATH_LINE`, `ENDING`, `FINAL_CARD`, `INTRO_SCENES` (5 scenes + title card), `CHAPTERS`. |
| `scripts/game/LevelController.gd` | **Distractors** visible and named (3D label): −5 s, educational message, do not count toward the recipe. **Collection timer** (HUD), paused in dialogues / menus / death; time bonus at the end. **Physical obstacles** placed through `world.add_obstacles()`, away from items, refills, station and workbench. **Single death** (`_death_active` lock): controls frozen, oxygen and timer stopped, collapse, close camera (an angle without obstacles, checked by raycast), desaturation and dark vignette, subtitle "Mima... I have failed you." spoken by the chosen avatar, then **MISSION FAILED / Your promise is not over.** with **RETRY FROM CHECKPOINT** / **MAIN MENU**. Checkpoint = shore entrance, air at 100, items already collected kept, hearts / profile / levels kept. Running out of air no longer costs a heart. **Workbench**: the camera moves to a table where the items **actually collected** (from `GameState.inventory`) appear one by one with their names, then "Here's what you recovered. Now let's give these materials a second life.", then the steps. Each step flattens the items (visible transformation); "place" steps make the matching item jump. The reward appears on the workbench. |
| `scripts/ui/RecyclingPuzzle.gd` | Panel docked on the right (the workbench stays visible). "place" step = cards for the items actually collected. "choice" step (process choice with explanation). Every step shows **WHAT TO DO** and **WHY IT MATTERS**, then the success text. |
| `scripts/ui/GameHUD.gd` | "KEEPER: <NAME>", timer (−5 s flash), dark death vignette, educational message (`toast_tip`). Oxygen appearance unchanged. |
| `scripts/ui/StoryDialog.gd` | Speaker PLAYER/YASSINE replaced by the player's name; `{name}` substituted; portrait of the chosen avatar; `radio_mode` (Mima speaks by radio, or in person at the end). |
| `scripts/ui/IntroVideo.gd` | Illustrated story from `INTRO_SCENES`: 5 scenes with the new images, one line at a time (narrator / Mima / player), crossfades, then title card with the official logo + "Every thread is a beginning." The optional `.ogv` video is still supported (none is provided or generated). |
| `scripts/Main.gd` | Flow: menu → profile → intro → chapter card → shore … → epilogue card → ending. CONTINUE. **Chapter cards ~3.6 s** (image, chapter, achievement from the previous shore; the next shore loads behind the card). Portrait of the avatar rendered once for the dialogues. |
| `scripts/game/Ending.gd` | Mima in person (`radio_mode = false`). After the mask comes off and the gifts are given: "Oh, my child... I remember this blue." / "I kept my promise, Mima." / "And you gave the world a reason to hope again.", then the blue thread, then a final card "One promise. Three shores. A future to restore." (~4 s), then stats. |
| `scripts/world/Boy.gd` | 6 avatars on the same skeleton / controller / gear: skin, hair (short, short curly, long, curly) or hijab; eyelashes for the girls. `frozen`, `collapse()` (stagger → kneel → fall, stays on the ground), `revive()`. |
